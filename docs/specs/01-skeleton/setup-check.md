# 설치 시험 체크리스트 — C5 (SC-001 Windows 일부)
기준: 사용자 행동 ≤ SETUP_MAX_ACTIONS(3), OS 확인 창 ≤ WIN_OS_PROMPTS(2), 로그인·허브 주소 입력 0.
행동 = 사용자가 직접 정하는 일(누르기·입력). OS 확인 창 = 예/허용만 누르는 창. 브라우저의 「다운로드 계속」 같은 경고 창은 OS 확인 창으로 따로 센다.

| # | 단계 | 셈 |
|---|---|---|
| 1 | 다른 기기(폰·PC)의 웹앱에서 「기기 추가」를 누른다 → 코드와 설치 링크가 나온다 | 행동 1 |
| 2 | 새 PC 에서 설치 링크를 열어 `webdesktop-agent.exe` 를 받아 실행한다 | 행동 2 · 경고 창(브라우저 「흔히 받지 않는 파일」 1, SmartScreen 「Windows 의 PC 보호」 1) |
| 3 | 에이전트 창에 코드 8자리를 넣는다 → 웹앱 목록이 「켜짐」 | 행동 3 |
