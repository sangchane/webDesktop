# SPEC 02 — 폰·태블릿 조작감과 자체 가상 키보드 (M)

목표: goals.md 목표 2 · SC-011 (근거 research/touch-control.md)

## FRAME
- 사용자: 밖에서 iPhone(390px) 이나 iPad(1024px) 로 집 PC(1920×1080 이상)를 다루는 본인.
- 문제: 화면이 0.2~0.5배로 보여 못 읽고 못 누른다. 시스템 자판엔 Esc·F키·방향키가 없고 화면을 가린다.
- 안 할 것: 호스트 해상도를 폰에 맞추기(에이전트 일, T9 뒤), 캔버스 잠금, 키 반복 속도 설정, 진동(iOS 미지원).

## 동작
| 손짓 | 트랙패드(폰 기본) | 직접 터치(태블릿 기본) |
|---|---|---|
| 탭 | 커서 자리 클릭 | 누른 곳 클릭 (DOUBLE_TAP_MS 안 두 번째 탭은 첫 탭 자리 → 더블클릭) |
| 한 손가락 끌기 | 커서 이동(상대) | 스크롤 |
| 탭 후 곧바로 끌기 | 왼쪽 끌기 | — |
| 길게(LONG_PRESS_MS) | — | 떼면 오른쪽 클릭, 끌면 왼쪽 끌기 |
| 두 손가락 탭 | 오른쪽 클릭 | 오른쪽 클릭 |
| 두 손가락 | 처음 움직임으로 정함: 손가락 사이가 벌어지면 확대(끝까지), 아니면 스크롤 | 확대·이동 |
- 확대: 1~ZOOM_MAX 배, 화면 밖으로 빈 곳이 보이지 않게 가둔다. 트랙패드는 커서가 가장자리 PAN_EDGE_PCT 안에 들면 따라간다. 확대 중이면 구석에 「2.4배 · 원래대로」.
- 조작 방식은 「⋯」 메뉴에서 바꾸고 localStorage 에 기억한다. 기본값은 화면 짧은 변 ≥ TABLET_MIN_PX 면 직접 터치.
- 가상 키보드: 막대 「키보드」로 연다. 화면 아래에 붙고 영상 영역이 그만큼 줄어든다(가리지 않음).
  층 3개 — 글자(QWERTY, 한글이면 두벌식 자모 표시, Shift 한 번), 기호(숫자·기호), Fn(F1~F12·방향·Home/End/PgUp/PgDn·Ins·PrtSc).
  글자는 웹앱이 조합한 버퍼를 기존 `Converter::text` 비교에 넣는다(한글 조합 중 바뀐 글자 = Backspace + 새 글자). Ctrl·Alt·Win 을 잡았으면 글자 대신 HID 키.
  Backspace·방향키는 길게 누르면 반복. 키 높이 ≥ 34px(가로 폰), 세로 폰 44px.

## 코드 위치
- `crates/web/src/input.rs` — 손짓 판정(두 방식·탭 후 끌기·길게·두 손가락 분류). 순수, 단위 시험.
- `crates/web/src/zoom.rs`(새) — 확대·이동·가두기·따라가기 셈. 순수, 단위 시험.
- `crates/web/src/hangul.rs`(새) — 두벌식 조합·지우기. 순수, 단위 시험.
- `crates/web/src/vkbd.rs`(새) — 가상 키보드 화면(Leptos). `remote.rs` 는 배선만.
- `crates/web/index.html` — 스타일. 바닥선: 오류 삼킴 없음(localStorage 실패는 기본값), 접근성(키마다 aria-label, 눌린 수정키 aria-pressed).

## 완료 기준
1. `cargo test -p web` — 두벌식 「안녕하세요 원격 테스트」 자판 순서 → 같은 글, 겹받침·받침 넘기기·지우기, 확대 가두기·따라가기, 손짓 판정.
2. `node --test tools/web.test.mjs` 폰 시험 — 가상 키보드로 한글 문장·Ctrl+C·F5 가 input 채널로 같게 간다, 집기 확대 뒤 탭 좌표가 확대 전 계산과 맞다, 키보드를 열어도 끊기·키보드가 390 안에 있다.
3. 정답지: 2의 비교 값은 사람이 정한 기대값(문장·HID 표 USB HID Usage Tables 0x07)이다.
